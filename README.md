### how to run code 
clone  the repository into your machinery by typing git clone https://github.com/travinne/react-todo-app.git
afterwards install dependancies by typing (git install)
to see the project on your browser type (npm start) in order to deploy the server

### tech used in developmment
.react
.javascript
.css 

### project structure 
src/
├── components/
│   ├── AddNewtodo.js      # Component for adding a new task to the to-do list
│   ├── Todolist.js        # Component displaying the to-do list together with checkboxes
│   └── CountTask.js       # Component showing task count (done/left)
├── App.js                 # Main component where state and props are called
└── index.js               # contains app.js
└── index.css              # contains all the styling

### features of the to-do app
.allows you to add new task
.allows you to mark task as complete or incomplete
.allows real time task count updates
